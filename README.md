# Computational Finance (AI Plus One)

## About the book

This 13-chapter compact rough draft is for MBA or advanced undergraduate readers who know present value, returns and either Excel or introductory Python. Learn to specify a financial model, build it in one tool, and check its output independently before defending an instrument, risk or portfolio decision. It uses fictional cases, not live trading or a hosted AI service.

## How to teach or study it

Start with a dated hand calculation. The model sequence moves through instruments, portfolio risk and a reconciled forecast so that the final [analyst model packet](assessment/analyst-model-packet.md) can be challenged by a reviewer. Use the [two-implementation lab](labs/two-implementations.md) to check units, dates and constraints in Excel or Python. Python checks were run; the Excel recipes have not been run in Excel.
